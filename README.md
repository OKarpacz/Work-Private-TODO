# ⚖️ Work-Private-TODO

> **The Task Manager That Protects Your Personal Time**

A revolutionary productivity app that automatically blocks work tasks after hours—because true productivity means knowing when to stop working and start living.

---

## 🎯 The Problem We're Solving

**Burnout is real.** In today's always-on work culture, we check work emails at dinner, finish presentations at midnight, and never truly disconnect. The line between work and personal life has disappeared.

**Work-Private-TODO** draws that line back—automatically.

---

## 💡 How It Works

### **The After-Hours Shield**

Set your work hours end time (e.g., 5:00 PM), and the app automatically hides all work tasks after that time. No more "just one more email." No more late-night project anxiety.

**During Work Hours** → Access all your tasks (work, personal, home)  
**After 5 PM** → Work tasks disappear automatically  
**Focus Shifts** → Only personal and home tasks remain visible

It's not about working less—it's about protecting your right to disconnect.

---

## ✨ Key Features

### **🛡️ Automatic Work Task Blocking**
Set your work hours end time, and the app automatically hides all work-related tasks once the clock strikes your chosen hour. Your evenings are yours again.

### **📋 Three Task Categories**
- **Work** – Professional tasks, meetings, and deadlines (hidden after hours)
- **Private** – Personal goals, hobbies, and self-care
- **Home** – Household chores and family responsibilities

### **⚡ Smart Task Management**
- Priority levels (Low, Medium, High)
- Due dates and times
- Task assignments for collaboration
- Completion tracking
- Detailed descriptions

### **🎨 Beautiful Interface**
Clean, modern design built with React and TypeScript. Intuitive navigation that makes task management actually enjoyable.

### **🌙 Dark Mode**
Easy on the eyes for late evening personal task planning (because personal time deserves comfort too).

### **📊 Multiple Views**
- **Dashboard** – Quick overview of today's tasks
- **Task List** – Detailed task management with category filters
- **Weekly Widget** – Plan your week ahead
- **Yearly View** – Long-term perspective on your goals

### **🔔 Customizable Settings**
- Set your own work hours end time
- Notification preferences
- Dark/light mode switching

## 🚀 Quick Start

Get started in under a minute:

```bash
# Clone the repository
git clone https://github.com/OKarpacz/Work-Private-TODO.git

# Navigate to the project
cd Work-Private-TODO

# Install dependencies
npm install

# Launch the app
npm run dev
```

Visit `http://localhost:3000` and start protecting your personal time today.
